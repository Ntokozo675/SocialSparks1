# SocialSparks 
## 1. Social Sparks Android Application
I designed Social Sparks in Android Studio using Kotlin. I designed it to help users with their social lives.
the app provides social suggestions for users based on the time of the day they input.
## 2. Design and Layout
When creating the app my goal was to keep the interface clean, clear and simple. I paid attention to colors,using darker and lighter colors
to create contrast. I used lighter pink of shade for my background and a darker shade of pink to make my buttons and text visible and clear, 
I used spacing and padding to make sure that my layout is not clustered, and everything is in place.
## 3. GitHut
I used GitHub to store my Android Studio Project filed. I also used it to keep track of changes made in the project
I used it create to my Readme that can help anyone understand by project just by reading.
## 4. GitHub Actions 
I used GitHub actions to configure my GitHub repository. the workflow was used to build and check the android project
